| **Availability Zone** | An availability zone is one or more isolated data centers with independent power and networking inside an AWS region. | AWS EC2 Dashboard - Service Health / Zones |
| **Console** | The AWS Management Console is the web-based interface used to view and manage cloud services in a browser. | AWS Management Console Home screen |

| **Policy** | An IAM policy is a document written in JSON that defines which actions are allowed or denied on specific AWS resources. | IAM Console - Policies screen |
| **Instance** | An EC2 instance is a virtual server running in the AWS cloud that you can launch and configure like a computer. | EC2 Console - Instances screen |
| **Bucket** | An S3 bucket is a cloud storage container used to hold files and folders as objects in Amazon S3. | S3 Console - Buckets screen |
| **Security Group** | A security group acts as a virtual firewall that controls which network traffic is allowed to enter or leave an EC2 instance. | EC2 Console - Security Groups screen |
